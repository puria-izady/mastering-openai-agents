# Lab 00: Codex as an Agentic Developer

## Goal

Practice how to work with Codex before asking it to build OpenAI agent systems.

## What You Build

A tiny Python CLI utility with:

- `AGENTS.md`
- Tests
- README
- One intentional bug
- One Codex-driven bug fix

## OpenAI Agents Concepts

None yet. This lab is the setup for using Codex effectively.

## Codex Concepts

- Inspect before editing
- Ask for a small plan
- Scope one change at a time
- Require tests
- Review diffs
- Ask Codex to explain verification

## Reference Solution Scope

Build a simple `text-stats` CLI:

- Input: text file path
- Output: word count, line count, top 5 words
- Tests: punctuation handling, empty file, repeated words

## Checkpoint

You can explain why "build the whole agent app" is a poor first Codex
prompt and can write a narrower prompt for one increment.
